# 设计说明

把设计稿链接、关键交互和视觉约定放在本目录。实现 H5 或小程序时以这里和现有页面为准，不要另起一套信息架构。

当前 H5 为移动宽度、底栏导航（今日 / 课程 / 统计等）。完整视觉以现网页面为准，设计稿补齐后在此追加文件。

## 视觉基调：阴影 + 渐变

界面不用可见描边表达层级，统一用「柔和投影 + 内高光」制造立体感。令牌定义在 `apps/web/src/styles/global.css` 的 `:root`（暗色主题在 `html[data-theme="dark"]` 有同名覆盖）：

- `--elev-sm` / `--elev-md` / `--elev-lg`：由近及远的三级投影，卡片按信息层级选用。
- `--glow-top`：卡片顶部 1px 内高光，替代原来的 `border: 1px solid var(--line)`。
- `--accent-gradient`：主操作按钮、选中态、底栏新增按钮与品牌 Logo 的暖橙渐变。
- `--line`：仅保留给分隔线与输入框的 `inset` 描边，不再用于卡片外框。
- `--glass-bg` / `--glass-edge` / `--glass-blur`：iOS 液态玻璃三件套（表面高光渐变、折射白边内阴影、`blur + saturate` 滤镜）。顶部 `AppHeader` 与底栏、快捷菜单共用这套令牌，明暗主题各自覆盖取值。悬浮层要透出底层内容时用它，不要改回实色 `--paper`。

新增卡片时不要写死颜色和阴影，直接用上述令牌；确需强调的容器再叠加一层带主色的投影（见课程卡）。

## 课程配色

课程主色是**饱和品牌色**，定义在 `apps/web/src/domain/constants.ts`：

- `COURSE_COLORS`：8 个可选主色（紫 / 粉 / 绿 / 蓝 / 品紫 / 橙 / 青 / 石板灰）。
- `COURSE_ICON_COLORS`：按课程图标给出的默认主色，新建课程切换图标时自动跟随。

页面不直接使用主色填充大面积背景，而是派生两个变量：

- `--course-color`（`--card-tint`）：课程主色，来自 `course.color`。
- `--course-deep`（`--lesson-deep`）：`color-mix` 出的深色端，用于渐变收尾、图标底、进度条尾色和环形进度文字。

由此得到统一做法：卡片背景是主色 12%~14% 到白色的斜向渐变，图标块是主色到深色端的渐变加主色投影，进度条是主色到深色端的横向渐变（每门课自带颜色），环形进度用 `conic-gradient` 从深色端起笔。

历史数据里的旧主色（早期深色与后来的浅彩色）在 `apps/web/src/data/storage.ts` 的 `LEGACY_COLORS` 中映射到新主色，读取快照时自动迁移，无需用户手动改。

## 时间轴与图表

- 今日/日历课程时间轴中的时间文字跟随课程主色；多孩子家庭的参与头像放在时间轴上并纵向排列，单孩子家庭不重复展示头像。
- 孩子头像用 `apps/web/src/assets/user_icon.png` 一张四宫格雪碧图，由 `components/ChildAvatar.vue` 用 `background-size` / `background-position` 裁成圆形；不要拆成四张图。创建孩子时必须从四套角色里选一张。
- 平台品牌主色使用暖橙（`#ff7a45`），课程自身仍保留多彩主色，避免把“平台操作”和“课程身份”混为一色。
- 趋势图使用圆角贝塞尔曲线、渐变描边和渐隐面积；环形图使用连续暖色渐变、圆形内阴影和柔和投影，避免生硬折线与纯色扇区。
- 横向滚动的卡片列表（如统计页课程明细）用「负外边距 + 同值内边距」给投影留出空间，不要让滚动容器直接切掉卡片下沿。

## 底部导航与新增入口

底栏是「4 个页签 + 中间凸起的新增按钮」，样式集中在 `global.css` 的 `.tabbar` / `.tabbar-fab` / `.quick-menu`，结构在 `components/TabBar.vue`：

- 底栏与快捷菜单是液态玻璃面板（`--glass-bg` / `--glass-edge` / `--glass-blur`），底层内容必须能透出并被模糊，不要用接近不透明的底色。
- 新增入口只有底栏中间这一个，页面内不再放悬浮 FAB；按钮用两层半透明白环（`color-mix(var(--paper), transparent)`）与底栏衔接出弧形缺口，实色白环会在玻璃上压出一块死板的白斑。
- 快捷菜单（新增日期安排 / 新增课程 / 记一笔账单）在底栏上方居中弹出，遮罩点击即关闭，路由变化时自动收起。
- 「新增日期安排」跨页触发：`composables/useQuickAdd.ts` 记录一个待处理标记，今日页在挂载或标记变化时消费并打开课程预设弹层。
- 快速新增弹层里的时间用 `components/AppTimeSelect.vue`（15 分钟粒度的时间网格），当天已有安排的时间点置灰加删除线并给出占用课程名；弹层下方列出当天占用时段，提交按钮不可点时必须显示原因文案，不做静默禁用。
- 选中态高亮 `.tabbar-indicator` 仿 iOS 液态玻璃：只用白色半透明与极淡冷调，不掺品牌橙；顶部条状高光 + 白色折射边缘 + 底部聚光，切换时用 GSAP 做横向拉伸再弹回。图标与文字颜色仍用 `--accent-text`（暗色 `#ffb08d`），高亮块不承担配色职责。
- 今日页签用时钟图标（表达“当天”），不要用房子图标——首页概念在本应用里就是“今天的安排”。
- 层级约定：底栏 `900` < 快捷菜单 `950` < 弹层/日期选择/孩子选择等浮层 `1100`，新增浮层沿用这一档位，别让底栏盖住弹层。
