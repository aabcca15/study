# 产品概述

**Uday家庭课表计划**：家长用来跟踪孩子学校课、兴趣班课表以及相关费用。

## 核心对象

- 孩子（至少保留一个）
- 课程（可共享给多个孩子）
- 排课与例外
- 账单（按孩子记账，可关联课程）
- 目标
- 学习统计（课时完成度与费用趋势）

## 当前形态

- 网页 H5：`apps/web/`，账号密码登录，数据在 `server/` 的 SQLite。
- 微信小程序：`apps/miniprogram/`，微信 openid 登录，数据在微信云数据库。功能与网页对齐：今日、日历、课程、账单、统计，另有家庭邀请和创建者 / 家长 / 家人三种角色。
- 两边规则相同，数据不互通。整体说明见 `.cursor/skills/myhome-project/SKILL.md`。小程序发布步骤见 `docs/miniprogram-launch.md`。

## 课程档案口径

- 家长按孩子维护课程安排，课程卡同时展示排课进度、教学生命周期和本期结算摘要。
- 教学生命周期与费用结算相互独立：已结课不代表已结清，已结清也不代表课程结束。
- 已结束/已结课课程置灰保留，方便查看历史；有效课程优先排列。
- 家长可从课程卡编辑排课、标记结课、恢复课程或进入账单处理待支付费用。

## 后续形态

- 若网页和小程序要看到同一个家庭，再让云函数改调 Nest，或做一次性导入。在那之前不要假设两端共库。
