# 产品概述

**小树成长**：家长用来跟踪孩子学校课、兴趣班课表以及相关费用。

## 核心对象

- 孩子（至少保留一个）
- 课程（可共享给多个孩子）
- 排课与例外
- 账单（按孩子记账，可关联课程）
- 目标
- 学习统计（课时完成度与费用趋势）

## 当前形态

移动端 H5。数据仅在本机浏览器。

## 课程档案口径

- 家长按孩子维护课程安排，课程卡同时展示排课进度、教学生命周期和本期结算摘要。
- 教学生命周期与费用结算相互独立：已结课不代表已结清，已结清也不代表课程结束。
- 已结束/已结课课程置灰保留，方便查看历史；有效课程优先排列。
- 家长可从课程卡编辑排课、标记结课、恢复课程或进入账单处理待支付费用。

## 后续形态

- Node.js 服务端，多端登录与同步
- 微信小程序与 H5 共用后端
