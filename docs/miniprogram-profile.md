# 小程序资料：直接复制到微信后台

小程序名称已定为 **Uday家庭课表计划**。下面按微信公众平台「设置 → 基本设置」的栏目写好。带「复制」的段落整段粘贴，不要再加词。

字数按微信规则计算：一个汉字算 2 个字符，一个英文字母算 1 个字符。依据是[小程序名称设置规范](https://kf.qq.com/faq/170109umMvm6170109MZNnYV.html)和[功能介绍长度说明](https://developers.weixin.qq.com/doc/oplatform/openApi/miniprogram-management/basic-info-management/api_setsignature.html)。功能介绍一个月大约只能改 5 次，提交前先通读一遍。

名称如果提示已被占用，不要在后面堆关键词。改用备选名 **Uday家庭课表**（去掉「计划」），功能介绍开头也改成「Uday家庭课表」。

## 名称

复制：

```text
Uday家庭课表计划
```

16 个字符（Uday 占 4，六个汉字占 12）。要求是 4–30 个字符。

## 简称

简称必须从名称里按顺序截取，长度 4–10 个字符，显示在微信任务栏。

复制：

```text
家庭课表
```

8 个字符，是名称中「家庭课表」这一段。任务栏更短，也方便别人搜索。

若希望任务栏带上品牌，改为 `Uday家庭课`（正好 10 个字符）。不要填 `Uday家庭课表`，那是 12 个字符，超过简称上限。

## 功能介绍

后台这一栏也叫简介。只贴下面这一句。它会出在小程序资料页和搜索结果里，上限 120 个字符。

复制：

```text
Uday家庭课表计划用来查看孩子的上课时间和地点，记录课程支出，并邀请家人一起看课表。
```

约 75 个字符。句中含有名称里的 Uday、家庭、课表、计划，并写了实际功能：上课时间、地点、课程支出、邀请家人。

## 功能说明

微信没有单独的「详细介绍」输入框。下面这段不要贴进功能介绍。留给审核备注，或以后页面里的关于说明。

```text
Uday家庭课表计划给家长记录孩子的学校课和兴趣班。今日和日历查看上课时间、老师和地点；课程页管理排课和进度；账单和统计查看课程支出。创建者可以邀请家长一起修改，或邀请家人只看课表和地点，方便接送。使用微信身份进入，不需要另外注册账号。
```

## 提交审核时的备注

复制：

```text
本小程序名称是 Uday家庭课表计划。用微信身份登录，不需要测试账号和密码。
打开后在登录页选择孩子头像并填写名字，点「创建并进入」即可看到今日课表。
底栏 ＋ 菜单里的「邀请家人」可生成邀请码。可以记录课程支出，不涉及微信支付。
```

## 填写时注意

- 名称、简称、功能介绍要一致，不要另写「Uday家庭课表计划」。
- 不要写在线教学、培训机构、免费、最全这类词。类目选不需要办学许可证的工具类。
- 发布后在后台打开「允许被搜索」。对外说全名「Uday家庭课表计划」，简称搜索不一定能找到。
