# 微信小程序上线步骤

这份文档给第一次发小程序的人。按顺序做。每一步后面都有「怎样算做完」。做完再进下一步。

Uday家庭课表计划的小程序不需要自己买服务器，也不需要开通微信支付。登录和数据都在微信云开发里。网页版是另一套数据，上线小程序时不用管网页。

做之前先把仓库拉到这台电脑，并且已经能打开终端。Windows 用 PowerShell 时，两条命令分开执行，不要写在一行用 `&&` 连接。

## 0. 先准备这些

- 一个已经实名的微信。这个微信号将成为小程序管理员。
- 管理员本人的身份证。注册个人主体时要扫脸。
- 一个能收验证码的手机号，和一个没有注册过公众平台的邮箱。
- 电脑上安装 Node.js 18 或更新版本。终端执行 `node -v` 能看到版本号即可。
- 安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)。稳定版即可。

怎样算做完：`node -v` 有版本号，开发者工具能打开。

## 1. 注册小程序账号

1. 浏览器打开 [https://mp.weixin.qq.com](https://mp.weixin.qq.com)，点注册。
2. 类型选「小程序」，不要选公众号或服务号。
3. 用准备好的邮箱注册，并按邮件完成激活。
4. 主体类型选「个人」。家庭课表给自己和家人用，个人主体就够。企业主体以后再迁也可以，现在不必办营业执照。
5. 按页面用管理员微信扫码，完成身份证和人脸核验。
6. 注册成功后进入小程序后台。

怎样算做完：能登录 mp.weixin.qq.com，左侧能看到「开发管理」。

## 2. 记下 AppID

1. 后台左侧打开「开发管理」→「开发设置」。
2. 复制「开发者 ID」里的 AppID。它以 `wx` 开头，后面是一串字母和数字。
3. 先存在记事本里。下一步要填进两个文件，两处必须是同一个 AppID。

不要使用开发者工具里的「游客模式」或 `touristappid`。游客没有微信身份，云函数会拒绝登录。

怎样算做完：记事本里有一串以 `wx` 开头的 AppID。

## 3. 把 AppID 写进项目

用编辑器打开仓库里的两个文件，把上一步的 AppID 贴进去。

1. `apps/miniprogram/project.config.json` 里的 `"appid"`。现在是空字符串。
2. `apps/miniprogram/src/manifest.json` 里 `mp-weixin` 下的 `"appid"`。不要改最外层那个 `"appid": "__UNI__MYHOME1"`，那是 uni-app 自己的应用标识。

`src/config.ts` 里的 `CLOUD_ENV` 先保持空字符串。空着表示使用开发者工具当前选中的云环境。

怎样算做完：两个文件里的微信 AppID 相同，并且都不是空的，也不是 `touristappid`。

## 4. 在这台电脑装依赖并打包

在仓库根目录 `myhome` 打开终端，依次执行：

```text
npm install
npm run build:cloud
npm run build:mp
```

- `npm install` 安装网页、服务端和小程序的依赖。
- `npm run build:cloud` 生成云函数文件 `apps/miniprogram/cloudfunctions/api/index.js`。改过云函数源码后都要重新执行这一条，再重新上传。
- `npm run build:mp` 生成小程序代码 `apps/miniprogram/dist/build/mp-weixin/`。这个目录不进 git。换电脑后必须重新打包，不能只拷贝别人电脑上的 dist。

然后进入云函数目录安装它自己的依赖：

```text
cd apps/miniprogram/cloudfunctions/api
npm install
```

装完后回到仓库根目录。

怎样算做完：存在 `apps/miniprogram/cloudfunctions/api/index.js`，也存在 `apps/miniprogram/dist/build/mp-weixin/app.json`。云函数目录里有 `node_modules`。

## 5. 用开发者工具打开项目

1. 打开微信开发者工具，用管理员微信扫码登录。
2. 导入项目。目录选 `apps/miniprogram` 这一层，不要选仓库根目录，也不要只选 `dist`。这一层同时有小程序和 `cloudfunctions`。
3. AppID 选你自己的，不要选测试号或游客。
4. 导入后看 `project.config.json` 的 `miniprogramRoot`。做完第 4 步的正式打包后，它应是 `dist/build/mp-weixin/`。
5. 如果模拟器是白屏或还是旧页面：菜单里「清缓存」→「全部清除」，再点「编译」。

日常改页面时，也可以在仓库根目录执行 `npm run dev:mp`，让它持续编译到 `dist/dev/mp-weixin/`。那时把 `miniprogramRoot` 改成 `dist/dev/mp-weixin/`，改完代码保存即可在工具里看到。准备上传审核时，改回 `dist/build/mp-weixin/` 并重新执行 `npm run build:mp`。

怎样算做完：模拟器里能看到 Uday 登录页，控制台没有 `touristappid` 或「游客模式」字样。

## 6. 开通云开发并建立数据库

1. 开发者工具顶部点「云开发」。第一次会要求开通，按提示同意协议。
2. 创建一个环境。名字可以用 `myhome-prod`。环境有免费额度，家庭自己用足够。记下环境 ID，需要的话填进 `src/config.ts` 的 `CLOUD_ENV`。不填也可以，只要工具右上角选中的就是这个环境。
3. 打开云开发控制台的「数据库」，新建三个集合，名字必须完全一致：
   - `users`
   - `families`
   - `invites`
4. 每个集合的权限选「所有用户不可读写」，或自定义安全规则把 `read` 和 `write` 都设为 `false`。
   这样手机上的小程序不能直接改数据库，只能调用云函数。云函数使用管理员权限，不受这条限制。
5. 不要选「所有用户可读写」。那样任何人都能改别人的家庭数据。

怎样算做完：云开发概览里能看到环境 ID，数据库里有上述三个集合，权限都不是「所有用户可读写」。

## 7. 上传云函数

这一步把登录、课表、账单规则放到微信服务器上。只在自己电脑打包是不够的。

1. 确认第 4 步的 `npm run build:cloud` 已经执行过。源码在 `cloudfunctions/api/src/index.ts`，工具实际上传的是旁边的 `index.js`。
2. 在开发者工具左侧找到 `cloudfunctions/api`。
3. 右键 `api`，选择「上传并部署：云端安装依赖」。不要选不安装依赖的那个。第一次上传会稍久。
4. 上传成功后，到云开发控制台的「云函数」列表，确认有 `api`，更新时间是刚刚。

以后只要改了 `cloudfunctions/api/src/index.ts`，都要重新 `npm run build:cloud`，再右键上传部署一次。客户端如果先更新、云函数还是旧的，已经登录过的用户再次打开时，可能被建成一个新的空家庭。

怎样算做完：云函数列表里的 `api` 时间是这次上传的时间，状态正常。

## 8. 用自己的微信完整走一遍

开发者工具工具栏点「预览」，用管理员微信扫码。这次是真机，不是游客。

按这个顺序点：

1. 登录页选择头像，填写孩子名字，点「创建并进入」。应进入今日页。
2. 加一门课，回到今日或日历，能看到这节课。
3. 顶栏进入家庭，生成一个「邀请家人」的邀请码。
4. 用另一个微信扫预览码，在登录页选「加入家庭」，粘贴邀请码。第二个微信只能看课表和地点，不能改课，也看不到账单。
5. 回到第一个微信的家庭页，能看到两名成员。可以把第二个人移出。
6. 关掉小程序再打开。应回到原来的家庭，而不是又建一个新家庭。顶栏没有退出。

中途如果提示云函数调用失败：回到第 7 步确认 `api` 已部署，回到第 6 步确认三个集合都在，并且 AppID 不是游客。

怎样算做完：两个微信能处在同一个家庭里，家人不能修改课表。

## 9. 补齐小程序介绍和隐私说明

审核员看不到你的电脑，只能看到后台填写的资料和真机里的页面。

在 mp.weixin.qq.com 完成这些：

1. 「设置」→「基本设置」：上传头像。名称、简称和功能介绍按 `docs/miniprogram-profile.md` 里的「复制」段落粘贴。名称是「Uday家庭课表计划」。被占用时用该文档里的备选名，不要自己加搜索词。
2. 「设置」→「基本设置」→「服务类目」：选个人主体允许、并且不要求额外资质的类目。优先在「工具」里选效率、备忘录这一类。不要选「教育培训」或需要办学许可证的类目。页面如果提示要上传资质，就换一个不需要资质的工具类。
3. 「设置」→「服务内容声明」→「用户隐私保护指引」：
   - 说明会使用微信提供的用户标识完成登录和区分家庭成员。
   - 说明复制邀请码时会使用剪贴板。代码里用的是 `uni.setClipboardData`。
   - 不要勾选手机号、位置、相册、麦克风。这个小程序没有这些功能。
4. 开发管理里把管理员以外、需要提前试用的家人加为「体验成员」。体验成员才能打开后面上传的体验版。

怎样算做完：名称、头像、介绍、类目、隐私指引都不再显示未完成。

## 10. 上传代码并提交审核

1. 本地再执行一次 `npm run build:mp`，确认开发者工具编译的是 `dist/build/mp-weixin/`。
2. 开发者工具右上角「上传」。版本号填 `0.1.0`，备注写「首次发布：登录、课表、账单、家庭邀请」。
3. 回到 mp.weixin.qq.com「管理」→「版本管理」。刚上传的包在「开发版本」。
4. 点「提交审核」。审核备注复制 `docs/miniprogram-profile.md` 里「提交审核时的备注」。

5. 等待审核。个人小程序常见是一两天，也可能更久。审核期间可以继续用预览和体验版。
6. 审核通过后，版本管理里点「发布」。发布后，别人才能在微信里搜到并正式使用。发布前只有体验成员能打开体验版。

怎样算做完：版本管理里正式版状态是「已发布」，用一个没有开开发者工具的微信能搜到并打开。

## 11. 以后每次改完再发一版

1. 改完代码，在仓库根目录执行 `npm run build:mp`。
2. 如果改过云函数源码，再执行 `npm run build:cloud`，并在开发者工具里对 `api` 重新「上传并部署：云端安装依赖」。
3. 真机预览，把改过的页面点一遍。
4. 开发者工具「上传」一个新版本号，例如 `0.1.1`。
5. 后台提交审核，通过后再发布。不点发布，用户仍在用旧的正式版。

## 常见问题

**模拟器提示游客模式，或登录没反应。**  
AppID 仍是空的或 `touristappid`。回到第 3 步，清缓存后重新编译。

**提示请在微信内打开，或云函数没有 openid。**  
当前仍是游客。用自己的 AppID，并用微信扫预览码，不要在游客模拟器里测登录。

**提示云函数不存在或调用失败。**  
第 7 步没做，或上传的不是 `api` 这个名字。云开发环境要和工具当前选中的环境一致。

**数据库报集合不存在。**  
回到第 6 步，三个集合的名字核对拼写。

**第二个微信加入后能改课或能看账单。**  
邀请时选成了「邀请家长」。家人只读必须选「邀请家人」。

**审核被拒，原因是类目不符或缺少资质。**  
回到第 9 步，改成不需要资质的工具类，重新提交。不要在介绍里写在线教学、支付、直播。

**换了一台电脑，页面是空的或是旧的。**  
`dist` 不在 git 里。在新电脑执行第 4 步的三条命令，再用开发者工具打开 `apps/miniprogram`。
