# Uday家庭课表计划：用户流程

页面事实以代码为准。网页路由见 `myhome-backend-contracts/product-map.md`。下面是微信小程序现在的走法。

## 第一次打开

1. 登录页二选一。
2. **创建家庭**：选孩子头像，填写孩子名字，点「创建并进入」。名字输入框的提示跟着头像变：蓝衣男孩「小Y」、白帽男孩「小I」、粉衣女孩「小M」、紫衣女孩「小U」；空着提交就用这个提示当名字（`src/domain/avatar-names.ts`，课程页新增孩子同理）。云函数按 openid 新建 `families` 和 `users`，角色是创建者。
3. **加入家庭**：填写家长发来的邀请码和自己的称呼（爸爸/妈妈/爷爷/奶奶），点「加入家庭」。云函数把这个 openid 绑到邀请码上的家庭，角色按邀请码来。
4. 成功后进入今日页。之后这台手机再打开，若本机还有登录标记，就直接恢复原来的家庭，不再新建。

创建者家里还有别人时，不能再加入另一个家庭。只有自己一个人时，可以加入别的家庭，空的旧家庭会被删掉。

## 今日和日历

- 今日：按周看某一天的课。课来自全部未结课课程和排课例外，不按「当前孩子」拆开。
- 日历：月历上的色点是当天的课。点某一天看到和今日相同的课表。
- 创建者和家长可以新增安排、改这一次的时间和费用、取消这一次。家人只能看。
- 临时安排不进长期课程档案，但出现在当天课表里。

## 课程

- 课程页按当前孩子过滤。创建者或家长切换孩子，会写进家庭快照里的默认孩子；家人切换只留在本机。
- 可以新建、编辑、结课、恢复、删除。删除只属于这个孩子的课和未支付账单；共享课只解除关联。至少留一个孩子。
- 一门课可以选多个孩子。结课不自动结清账单，付清也不自动结束排课。

## 账单和统计

- 今日里的「本周课程账单」进入本周账单。统计页看月或年。
- 金额按账单净额算，退款会减少已付和合计。
- 家人的快照里没有 `expenses`、`payments`、`charges`，账单入口对他们不可用。
- 已支付账单不能改金额、不能删。未支付可以标记已支付或删除。

## 家庭成员

1. 底栏中间 ＋ 弹出菜单，最后一项「邀请家人」进入家庭页（家人看到的是「家庭成员」，菜单里只有这一项）。顶栏右侧只留主题切换，并让开微信右上角胶囊。
2. 「邀请家长 / 邀请家人」是同级分段切换，下方说明跟着角色变。创建者两个都有，家长只有「邀请家人」。切到某个角色时没有可用邀请码会自动生成一个。
3. 点「发给微信好友」分享当前邀请码；下方其它邀请码每行一个分享图标，分享的是那一行的码。对方打开后落在加入页，邀请码已填好。
4. 创建者可以移出家长和家人，不能移出自己。

## 再次打开

微信身份跟着这台微信走，顶栏没有退出。关掉小程序再打开，会回到原来的家庭。被移出家庭后，下次打开才回到登录页。
