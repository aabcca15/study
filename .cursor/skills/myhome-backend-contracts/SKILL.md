# 小树成长：业务与后端契约

当前 H5 用 `localStorage` 键 `myhome.v1` 模拟持久化。改业务或为后端做准备时，先读本文件再按需打开参考文档，不要只改页面组件。

## 必读顺序

1. 改 **页面交互 / 信息架构**：[product-map.md](product-map.md)
2. 改 **规则、接口、事务、迁移**：[backend-contracts.md](backend-contracts.md)
3. 改 **课程计价、课次费用、账单、支付与统计**：[billing-model-v2.md](billing-model-v2.md)
4. 设计 **登录、家庭、角色、微信账号**：[account-model.md](account-model.md)
5. 调整 **不合理逻辑或排优化**：[gaps-and-backlog.md](gaps-and-backlog.md)

代码事实源：`apps/web/src/domain/types.ts`、`apps/web/src/stores/app.ts`、`apps/web/src/services/`。契约必须与这三处一致。

## 开发要求

1. 先确认实体、关联、数据所有权（家庭 / 孩子 / 课程 / 账单）。
2. 区分纯 UI 状态与必须由服务端执行的规则。UI 状态：选中日期、底栏快捷菜单开合、主题、统计年/月切换。
3. 涉及服务端逻辑时更新 `backend-contracts.md`：规则、API、错误码、事务、权限、幂等、`myhome.v1` 映射。
4. Store 方法保持业务语义；级联删除、共享课、统计口径、时间冲突不要只写在 `.vue`。
5. 接入后端后以服务端结果为准；前端只做确认、请求状态和错误提示。
6. 发现不合理逻辑：先记入 `gaps-and-backlog.md`（状态：现状 / 建议 / 是否已改），再改代码。

## 当前核心约束

- H5 是家长端。今日、日历、统计默认家庭作用域；课程列表与账单页当前按会话选中的孩子过滤（缺口，见 backlog）。
- 未来孩子端登录后，同类页面只能看本人；客户端选择不能扩大授权。
- 至少保留一个孩子。共享课删孩子时只解绑，不删课。
- 课程生命周期与费用结算独立：结课不改账单，结清不结束排课。
- 排课例外跟课程走。独享课、该孩子账单与目标随孩子删除。
- 尚无登录。`SessionState.role` / `childId` 只是本地会话，不是账号。
